# บอท Poker

บอทใช้กติกา No-Limit Texas Hold’em ของโต๊ะเดิม และใช้กลยุทธ์ใหม่เป็นค่าเริ่มต้นสำหรับบอททุกตัว ทั้งบอทที่เลือกตอนสร้างห้องและบอทที่เพิ่มใน lobby

## สิ่งที่เปลี่ยน

| ก่อนปรับ | หลังปรับ |
| --- | --- |
| มีคู่หรือมี J/Q/K/A ก็ถือว่าแข็ง และ Call เมื่อราคาไม่เกิน 2 BB | ประเมินไพ่เริ่มต้น, ชุดไพ่ที่ได้จริง, โอกาสพัฒนาเป็น Straight/Flush และโอกาสชนะคู่แข่งหลายคน |
| เลือก Check / Call / Fold | มี Value raise, Semi-bluff, Steal, Continuation bet, Blocker bluff และ All-in ตามสถานการณ์ |
| ไม่เทียบราคา Call กับกองกลาง | เทียบ Equity กับ Pot odds โดยนับเฉพาะ Main/Side pot ที่มีสิทธิ์ชนะ |
| ไม่แยกคู่บนบอร์ดกับคู่ในมือ | แยกความแข็งแรงที่ไพ่ส่วนตัวเพิ่มให้จากการใช้ไพ่กลางร่วมกัน |
| ไม่พิจารณาการ Raise ก่อนหน้า | ปรับช่วงไพ่ที่เป็นไปได้ของคู่แข่งตามประวัติเดิมพันที่เปิดเผยในมือนั้น |

## การตัดสินใจ

1. อ่านไพ่ตัวเองสองใบ ไพ่กลาง ตำแหน่งปุ่ม Dealer จำนวนคู่แข่ง ชิปที่เหลือ ยอดเดิมพัน และประวัติการเล่นที่เปิดเผย
2. ให้ค่าน้ำหนักช่วงไพ่คู่แข่งจากการ Call / Raise ก่อนและหลัง Flop โดยเก็บความเป็นไปได้ของไพ่อ่อนหรือ Bluff ไว้ด้วย การถ่วงน้ำหนักเป็นการประมาณจากข้อมูลสาธารณะ
3. สร้างน้ำหนักคู่ไพ่ที่เป็นไปได้ทั้งหมดและสุ่มด้วย CDF; หากไพ่ชนกับที่จำลองให้คู่แข่งคนอื่น จะคำนวณน้ำหนักเฉพาะคู่ที่เหลือ โดยไม่แทนด้วยไพ่อ่อนแบบสุ่มทั่วไป จากนั้นจำลองไพ่กลางที่ยังไม่เปิด ค่าเริ่มต้น 96 ครั้งต่อการตัดสินใจ แต่ละรอบใช้ไพ่ไม่ซ้ำกันและนับส่วนแบ่งเมื่อเสมอ
4. คำนวณราคา Call และกองที่ชนะได้จริง เช่น ต้อง Call 50 เมื่อกองกลาง 150 หลัง Call จะมี 200 จึงต้องมีส่วนแบ่งคาดหวังประมาณ 25% เพื่อคุ้มราคา โดย Side pot ที่ไม่มีสิทธิ์ชนะและชิปส่วนที่ไม่มีคนรับเดิมพันจะไม่ทำให้ราคา Call ดูคุ้มเกินจริง
5. พิจารณาตำแหน่งที่ได้เปรียบหลัง Flop, Stack ที่คู่แข่งรับเดิมพันได้, SPR และโอกาสจั่วติด ก่อนเลือก Fold, Check, Call, Raise หรือ All-in
6. เลือกขนาดเปิดเดิมพัน/เพิ่มเดิมพันตามราคาเดิม กองกลาง ตำแหน่งและจำนวนคนที่ Call เข้ามา ผสมจังหวะรุกและชะลอด้วย RNG สำหรับกลยุทธ์

ตัวอย่างพฤติกรรมที่มี regression test: เปิด Raise ด้วยไพ่เริ่มต้นแข็ง, Value bet เมื่อถือไพ่เหนือกว่าจริง, ปล่อยไพ่ที่ไม่คุ้มราคา Call, เล่นต่อเมื่อ Draw แข็งและราคาเหมาะสม, ไม่ Raise เข้าใส่คนที่ All-in หมดแล้ว และไม่เพิ่มเดิมพันเพียงเพราะไพ่กลางเป็น Royal flush ที่ทุกคนใช้ร่วมกัน

กรณีทดสอบช่วงไพ่แคบ: ถือ QQ บนบอร์ด A♥ K♥ 7♦ 4♠ 2♥ เจอประวัติ Raise หนักและ River bet 800 เข้า Pot 800 แบบจำลองช่วงไพ่ที่กำหนดให้ Equity ประมาณ 14.61% ซึ่งต่ำกว่าราคาคุ้มทุน 33.33% จึง Fold การทดสอบตรวจเทียบการสุ่มกับการคำนวณคู่ไพ่ทั้งหมดใน fixture นี้; ตัวเลขเป็นผลตามสมมติฐานช่วงไพ่ ไม่ใช่โอกาสชนะที่รู้แน่นอนในการเล่นจริง

## ข้อมูลและกติกา

- Strategy รับเฉพาะ `PokerBotView`: ไพ่ของบอทเองและข้อมูลสาธารณะที่คัดเลือกจาก snapshot ไม่มีสำรับจริง ไพ่ส่วนตัวของผู้อื่น หรือผล Showdown ใน input
- สุ่มกลยุทธ์ด้วย Node `crypto.randomInt` คนละ stream กับ RNG แจกไพ่ จึงไม่เปลี่ยนลำดับไพ่จริงเมื่อบอทคิดมากหรือน้อย
- ประวัติเดิมพันใช้เฉพาะมือปัจจุบัน สูงสุด 128 รายการ ล้างเมื่อเริ่ม/เตรียมมือใหม่ และแยก All-in call กับ All-in raise
- ทุกการเล่นของบอทผ่าน `betAction` เดียวกับผู้เล่นจริง จึงยังต้องเคารพขั้นต่ำ Raise, Short all-in, สิทธิ์ Raise ที่ยังไม่เปิดใหม่, ยอดชิปและ Side pot
- แบ่งคำนวณเป็นช่วงและคืนเวลาให้ Node event loop ด้วย `setImmediate` พร้อมจำกัดจำนวนตัวอย่าง ยกเลิกงานด้วย `AbortController` เมื่อเทิร์นเปลี่ยน หมดเวลา หรือปิดเกม
- ก่อนใช้ผลคิดตรวจรอบ, phase, turn, deadline และสถานะผู้เล่นซ้ำ ผลจากเทิร์นเก่าจึงไม่สามารถลงเดิมพันย้อนหลังได้
- หาก Strategy คืนคำสั่งผิดกติกาหรือทำงานผิดพลาด จะ Check เมื่อผ่านฟรีได้ หรือ Fold เมื่อมีราคา Call โดยไม่วางเดิมพันที่ไม่ถูกต้อง

นี่เป็นบอทแบบใช้กฎกลยุทธ์ร่วมกับการประมาณความน่าจะเป็น ไม่ใช่ GTO solver หรือโมเดลที่ฝึกจากการแข่งขัน ไม่มีผลการวัด win rate ระยะยาวที่รับรองว่าจะชนะผู้เล่นระดับมืออาชีพ Range ของคู่แข่งและพฤติกรรมการ Call ในอนาคตยังเป็นการประมาณจากสถานการณ์ปัจจุบัน ไม่ใช่การเรียนรู้ผู้เล่นข้ามหลายรอบ

## โครงสร้างโค้ด

- `apps/server/src/poker-bot.ts`: วิเคราะห์ Equity, ราคา Call, ช่วงไพ่ และเลือก Action เป็นโมดูลแยกที่ทดสอบด้วย seeded RNG ได้
- `apps/server/src/poker-game.ts`: สร้างข้อมูลให้บอท คุมเวลา ประวัติเดิมพัน การยกเลิก และใช้ผลตัดสินใจผ่าน state machine
- `packages/shared/src/poker.ts`: ใช้ตัวประเมินมือ 5 ใบจาก 7 ใบและตัวแบ่ง Pot เดิม
- `tests/poker-bot.test.ts`: กลยุทธ์ Equity, Range, ข้อมูลที่ใช้, การแบ่งงานและขอบเขตการ Raise
- `tests/poker-bot-game.test.ts`: เทิร์นจริง การหมดเวลา ออกจากเกม ปิดเกม เดิมพันผิดกติกา และชิปกับโต๊ะหลายคน/Short stack

รัน `npm run test:poker-bots` เพื่อตรวจ Strategy และ Integration, `npm test` สำหรับทุกเกม, `npm run test:poker` สำหรับหน้าเล่นจริง และ `npm run build` สำหรับ production output
